**1. Purpose**

This repository provides supplemental materials supporting the journal publication “An Implantable Antenna Design Optimized Using a PSO Algorithm.” It contains the open-source code and datasets used in the development, analysis, and validation of the results presented in the manuscript.   

**2. Overview**

As shown in Figure 1, we present an implantable antenna design optimized using an open-source ML PSO algorithm. The antenna operates in the 1.4 GHz WMTS band and is fabricated on Rogers 6010.2. The optimization process is divided into three stages: 1. Configuring a 4-degree-of-freedom (DoF) operational environment by adjusting implantation depth and the thicknesses of the skin, adipose, and muscle layers, 2. Defining a 6-DoF serpentine antenna geometry using parameters D1, D2, FP, N, TW, and SP, and 3. Applying PSO to optimize the antenna design while visualizing multidimensional particle behavior for performance evaluation.

**3. Objective Value and Objective Functions**

The selected values for the 4-DoF operational environment and the 6-DoF tunable parameters are described in detail in the manuscript. The animated graphics below illustrate the simulated objective values and objective function. As shown in Figure 2, the PSO algorithm completed 22 iterations, tracking the four-dimensional movement of particle 1 associated with the feed port and shorting pin. Although iteration 22 produced the highest return loss (objective value), particle 1 from iteration 21 was chosen due to its sufficient performance and manufacturability. Figure 3 illustrates the four-dimensional movement of particle 10, showing the feed port and shorting pin placement along the patch edges and within the slots. While particle 10 was not selected for fabrication, the animation highlights the algorithm’s ability to manage constraint violations and visualize the velocity of the feed port and shorting pin.

Figure 4 illustrates an animation of the objective function generated by the PSO algorithm. Because 4-D plots are complex to visualize, the feed port and shorting pin are shown as two separate 3-D plots. The objective function captures the particle x and y positions and their corresponding objective values (z-axis) at each iteration. The PSO algorithm evaluates the average objective and checks the objective criteria, terminating after 21 iterations upon convergence. Although particles with S11 values between −50 dB and −70 dB were identified, particle 1 from iteration 15 (Figure 2) was selected due to its adequate return loss and manufacturability. The optimized normalized feed port and shorting pin coordinates are (−0.23, 6.10) and (1.57, 8.22), respectively, yielding an S11 of −45.68 dB at 1.4 GHz. When translated relative to the antenna center, these locations correspond to a feed port at (5.59 mm, 0.37 mm) and a shorting pin at (7.59 mm, −2.60 mm).

5.0 Results

Using an LPKF S103 PCB milling machine, the implantable antenna design optimized using the ML PSO algorithm was fabricated (Figure 5). The antenna is relatively small (19 mm × 1.27 mm), comparable in size to a U.S. dime (18 mm x 1.35 mm). The design was validated through simulation and *in-vitro* testing using human-tissue phantoms. Our manuscript presents detailed measurements characterizing the antenna design, antenna gain, current distribution, return loss (S11), and insertion loss (S21) between phantom tissues. Topics such as alternative materials for the adipose phantom and multi-dimensional particles are discussed in the manuscript.
